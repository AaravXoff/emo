# EMO songs

Add MP3, WAV, or OGG files that you have permission to use to this folder.
- Optional startup message: emo_is_ready.mp3 (played at startup if present).
- Say "sing" or use Play song on the remote to choose a random track.
- Without a ready MP3, EMO says "EMO is ready" with the configured speech engine.

No audio recordings are bundled here.
